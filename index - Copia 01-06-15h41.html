📖 Como Criar sua Nuvem Gratuita (Tutorial)

Siga estes passos para configurar seu próprio banco de dados online e usar este controle no celular e no computador ao mesmo tempo, sem perder os dados.

  1. Acesse o site Firebase Console e faça login com sua conta Google.
  2. Clique em Adicionar projeto (Dê um nome como "MeuControleFinanceiro" e aceite os termos. Você pode desativar o Google Analytics).
  3. Dentro do projeto, no menu esquerdo, vá em Criação > Firestore Database.
  4. Clique em Criar banco de dados (Mantenha as configurações de localidade recomendadas e confirme).
  5. Com o banco criado, clique na aba Regras (Rules) no topo da tela do Firestore.
  6. Mude a palavra false para true. O código deve ficar exatamente assim:
    allow read, write: if true;
  7. Clique no botão azul Publicar. (Isso destranca o cofre para o nosso sistema).
  8. Agora vá no topo esquerdo do painel, clique no ícone da engrenagem (⚙️) ao lado de "Visão geral do projeto" e escolha Configurações do projeto.
  9. Role a página até o fim. Onde diz "Seus aplicativos", clique no botão redondo de código </> (Web).
  10. Dê um apelido para o app (ex: "Controle Web") e clique em Registrar. Ignore a parte de "Hospedagem" (Hosting).
  11. Ele vai gerar um bloco de código. Copie apenas a parte interna que começa com apiKey: "..." até a última linha appId: "...".
  12. Volte para o nosso sistema, abra a aba acima (Sincronização e Acesso Online), mude para Nuvem, cole o código na caixa preta e clique em Salvar Chaves. Pronto!
